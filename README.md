# Research Paper Question Answering System

A lightweight Retrieval-Augmented Generation (RAG) assistant built using LangChain, ChromaDB, and Google Gemini to answer questions from academic research papers.

## Features
* Ingests and parses research papers in PDF format.
* Chunks document content using semantic splitting.
* Stores vector embeddings using ChromaDB.
* Answers targeted queries regarding paper objectives, methodologies, datasets, findings, and limitations.
* Grounded generation with source page citations.
